مراقب الصلاحيات — نسخة أولية قابلة للتجربة

المحتويات:
- index.html: التطبيق.
- manifest.webmanifest و sw.js: التثبيت والتشغيل دون اتصال بعد التحميل الأول.

مهم:
1) انسخ المجلد إلى استضافة HTTPS ثابتة (مثل GitHub Pages) وافتح الرابط مرة واحدة بمتصفح Chrome على Android.
2) من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
3) بعد تحميله أول مرة، يمكن فتحه دون إنترنت.
4) مسح الباركود بالكاميرا يحتاج HTTPS وإذن الكاميرا ومتصفحًا يدعم BarcodeDetector. يوجد إدخال يدوي بديل.
5) البيانات محفوظة محليًا في متصفح الجهاز. صدّر JSON دوريًا؛ مسح بيانات المتصفح قد يحذفها.
6) النسخة الحالية نموذج أولي: لا يوجد مزامنة بين الأجهزة، ولا تنبيه نظام مجدول عندما يكون التطبيق مغلقًا. تظهر حالات الاستحقاق عند فتح التطبيق.

التعامل مع الدفعات:
كل تسجيل لتاريخ انتهاء مختلف يُحفظ كدفعة منفصلة، حتى لو كان الباركود واحدًا.
